Описание колонок базы данных

USER
- id — уникальный номер пользователя.
- username — логин для входа в систему.
- first_name — имя пользователя.
- last_name — фамилия пользователя.
- email — почта пользователя.
- is_active — признак, что аккаунт активен и его можно использовать.

API_DEPARTMENT
- id — уникальный номер подразделения.
- name — название подразделения.
- created_at — когда подразделение было создано.
- updated_at — когда подразделение последний раз изменяли.

API_USERPROFILE
- id — уникальный номер профиля.
- user_id — какой пользователь связан с этим профилем.
- role — роль пользователя в системе, например ADMIN, DEPARTMENT_HEAD или WORKER.
- department_id — к какому подразделению относится пользователь.

API_EQUIPMENT
- id — уникальный номер оборудования.
- name — название оборудования.
- status — текущее состояние оборудования, например OPERATIONAL, BROKEN или EXPIRED.
- expiration_date — дата, когда срок службы оборудования заканчивается.
- photo — файл с фотографией оборудования.
- department_id — к какому подразделению прикреплено оборудование.
- created_at — когда оборудование добавили в систему.
- updated_at — когда запись об оборудовании последний раз меняли.

API_TASK
- id — уникальный номер задачи.
- title — короткое название задачи.
- description — подробное описание, что нужно сделать.
- assignee_id — пользователь, которому назначили задачу.
- creator_id — пользователь, который создал задачу.
- due_date — крайний срок выполнения.
- duration_hours — сколько часов примерно должно занять выполнение.
- status — состояние задачи, например PENDING или COMPLETED.
- created_at — когда задачу создали.
- updated_at — когда задачу последний раз обновляли.

API_COMMENT
- id — уникальный номер комментария.
- task_id — к какой задаче относится комментарий.
- author_id — кто написал комментарий.
- text — сам текст комментария.
- created_at — когда комментарий был добавлен.

API_INCIDENT
- id — уникальный номер инцидента.
- type — тип инцидента, например ACCIDENT или BROKEN_EQUIPMENT.
- description — описание того, что произошло.
- reporter_id — кто сообщил об инциденте.
- equipment_id — какое оборудование связано с инцидентом.
- status — текущий статус инцидента, например OPEN или RESOLVED.
- urgency — срочность инцидента, например HIGH или CRITICAL.
- created_at — когда инцидент был создан.
- updated_at — когда запись об инциденте последний раз изменяли.

API_MESSAGE
- id — уникальный номер сообщения.
- sender_id — кто отправил сообщение.
- receiver_id — кто получил сообщение.
- text — текст сообщения.
- created_at — когда сообщение было отправлено.
- read — прочитано сообщение или нет.
